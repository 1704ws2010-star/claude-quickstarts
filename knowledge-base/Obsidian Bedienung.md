# 📖 Obsidian Bedienung

Tipps und Tricks für optimale Obsidian-Nutzung in dieser Vault.

## ⌨️ Wichtige Shortcuts

| Shortcut | Aktion |
|----------|--------|
| **CMD/CTRL + P** | Schnelle Datei-Suche |
| **CMD/CTRL + Shift + F** | Globale Textsuche |
| **CMD/CTRL + G** | Graph-Ansicht |
| **CMD/CTRL + Alt/Opt + Pfeiltaste** | Zurück/Vorwärts navigieren |
| **CMD/CTRL + K** | Link einfügen |
| **CMD/CTRL + Shift + I** | Bild einfügen |

## 🗺️ Navigation

### Wege um zu navigieren:

1. **Sidebar (Links)** - Folder & Files anklicken
2. **Links folgen** - [[Links]] im Text klicken
3. **Breadcrumb** - Oben für Parent-Navigation
4. **Graph** - Visuelle Übersicht (CMD+G)
5. **Suche** - CMD+Shift+F

## 💾 Neue Dateien erstellen

```
1. Rechts-Click im Sidebar
2. "New note" wählen
3. Name eingeben
4. In Folder speichern
```

Oder direkt: `[[New Note Name]]` schreiben und dann Click.

## 🔍 Effektiv suchen

### Text-Suche
- `search term` - Einfache Suche
- `"exact phrase"` - Genaue Phrase
- `file:filename` - In bestimmter Datei
- `path:folder/` - In Folder

### Tag-Suche
- `tag:#python` - Alle Python-Notes
- `tag:#setup` - Alle Setup-Notes

## 🎨 Vault-spezifische Features

### Diesen Vault optimieren:

1. **Backlinks Panel** - Welche Dateien linken hierher
2. **Outline** - Übersicht der Überschriften
3. **Tag Panel** - Alle verwendeten Tags
4. **Quick Switcher** - CMD+P für schnelles Wechseln

## 📝 Markdown Tips

```markdown
# Überschrift 1
## Überschrift 2

- Liste
  - Nested

[[Link to Note]]
![[Image.png]]

| Table | Header |
|-------|--------|
| Data  | Cell   |

> Blockquote
```

## 🔗 Interne Links

### Format
- `[[Note Name]]` - Link zur Note
- `[[Note Name#Heading]]` - Link zu Überschrift
- `[[Note Name|Custom Display]]` - Mit Custom Text

### Graph nutzen
- Rechts unten: **Graph Icon** klicken
- Zoom mit Scroll
- Nodes klicken zum Öffnen
- Übersicht der Verbindungen sehen

## 💡 Best Practices für diese Vault

1. **Immer Tags nutzen** - Bessere Kategorisierung
2. **Backlinks folgen** - Zusammenhänge verstehen
3. **Graph regelmäßig anschauen** - Struktur verstehen
4. **Suche nutzen** - Schneller als navigieren
5. **Neue Notes verlinken** - Zur übergeordneten Note
