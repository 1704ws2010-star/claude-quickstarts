# Claude Quickstarts Knowledge Base

Dies ist eine Obsidian Vault mit vollständiger Dokumentation aller Claude Quickstart-Projekte und Best Practices.

## 📂 Struktur

- **[[Projects]]** - Alle Quickstart-Projekte im Detail
- **[[Setup & Entwicklung]]** - Setup-Guides für jedes Projekt
- **[[Code Standards]]** - Python, TypeScript und allgemeine Best Practices
- **[[Tools & Dependencies]]** - Werkzeuge, Befehle und Dependencies
- **[[Legal & Compliance]]** - Copyright und Dokumentationspflichten

## 🚀 Quickstart

Alle Projekte unter `Projects/` entdecken oder nutze die **Suche** (Cmd+Shift+F) um schnell zu finden, was du brauchst.
