## 💡 Tipps für Obsidian

1. **Links folgen:** CMD/CTRL + Click auf [[Links]]
2. **Zurück navigieren:** CMD/CTRL + Alt/Opt + Pfeiltaste
3. **Graph anschauen:** CMD/CTRL + G (unten links)
4. **Suchen:** CMD/CTRL+Shift+F durchsucht alles
5. **Schnell wechseln:** CMD/CTRL+P um Dateien zu finden
