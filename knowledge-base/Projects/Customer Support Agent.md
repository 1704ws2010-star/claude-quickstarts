# Customer Support Agent

#customer-support #typescript #frequently-used

Ein vollständiger TypeScript/React Customer-Support Chatbot mit moderner UI. Enthält mehrere Layout-Varianten (Full UI, Left/Right Sidebar, Chat-Only).

## 📋 Überblick

- **Sprache:** TypeScript/JavaScript
- **Framework:** React + Next.js
- **UI Library:** shadcn/ui
- **Komplexität:** Mittel
- **Fokus:** Customer Service Automation

## 🚀 Schnellstart

```bash
# Dependencies installieren
npm install

# Dev Server starten (Full UI)
npm run dev

# UI Varianten:
npm run dev:left    # Left Sidebar
npm run dev:right   # Right Sidebar
npm run dev:chat    # Chat Only
```

## 🛠️ Build & Deployment

```bash
# Production Build (Full UI)
npm run build

# Varianten siehe package.json für spezifische Build-Kommandos
```

## 📋 Qualität

```bash
# Linting
npm run lint

# Type Checking (via TypeScript)
```

## 📁 Struktur

- `src/` - React Komponenten und Logik
- `public/` - Statische Dateien
- `package.json` - Dependencies & Scripts

## 🔧 Code Style

- **Language:** TypeScript Strict Mode
- **Components:** Function Components mit React Hooks
- **Interfaces:** Proper Type Definitions
- **Formatting:** ESLint Next.js Configuration
- **UI:** shadcn/ui Component Library

## 🎨 Layout Varianten

1. **Full UI** - Komplette Interface mit Sidebar
2. **Left Sidebar** - Navigation links
3. **Right Sidebar** - Navigation rechts
4. **Chat Only** - Nur Chat-Interface
