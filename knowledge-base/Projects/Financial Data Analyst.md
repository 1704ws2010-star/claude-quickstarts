# Financial Data Analyst

#financial-analyst #typescript

Ein Dashboard für Finanzanalyse mit Datenvisualisierung. Nutzt Recharts für interaktive Grafiken und bietet umfangreiche Analysemöglichkeiten.

## 📋 Überblick

- **Sprache:** TypeScript/JavaScript
- **Framework:** React + Next.js
- **Visualization:** Recharts
- **Komplexität:** Mittel
- **Fokus:** Financial Data Analysis

## 🚀 Schnellstart

```bash
# Dependencies installieren
npm install

# Dev Server starten
npm run dev
```

## 🛠️ Build & Deployment

```bash
# Production Build
npm run build
```

## 📋 Qualität

```bash
# Linting
npm run lint
```

## 📁 Struktur

- `src/` - React Komponenten und Visualisierungen
- `public/` - Statische Assets
- `package.json` - Dependencies & Scripts

## 🔧 Code Style

- **Language:** TypeScript Strict Mode
- **Components:** Function Components mit Type Annotations
- **Visualization:** Recharts für Datenvisualisierung
- **State:** React Hooks für State Management
- **Formatting:** ESLint Next.js Configuration

## 📊 Features

- Interaktive Datenvisualisierung
- Finanzielle Metriken und KPIs
- Datenanalyse-Tools
- Responsive Design
