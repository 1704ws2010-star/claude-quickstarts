# Autonomous Coding

#autonomous-coding #python #important

Ein autonomer Code-Generator und Entwicklungs-Agent. Kann selbstständig Aufgaben analysieren, Code schreiben und Lösungen entwickeln.

## 📋 Überblick

- **Sprache:** Python
- **Fokus:** Autonomous Code Generation
- **Komplexität:** Hoch
- **Agent Type:** Multi-step Reasoning

## 📁 Struktur

- `prompts/` - System Prompts für den Agent
  - `initializer_prompt.md` - Initialisierungs-Prompt
  - `coding_prompt.md` - Haupt-Coding-Prompt
- `README.md` - Dokumentation

## 🧠 Prompts

### Initializer Prompt
Wird beim Start verwendet, um den Agent vorzubereiten und Kontext zu setzen.

### Coding Prompt
Haupt-Prompt für autonome Code-Generierung und Problem-Lösung.

## 🔧 Code Style

- **Functions/Variables:** snake_case
- **Classes:** PascalCase
- **Error Handling:** Custom ToolError
- **Types:** Vollständige Typ-Annotationen
