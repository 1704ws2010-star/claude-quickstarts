# Obsidian Vault Tags

Tags zur einfacheren Navigation und Kategorisierung.

## 🏷️ Verwendete Tags

### Nach Projekt
- `#computer-use` - Computer-Use Demo
- `#browser-use` - Browser-Use Demo
- `#customer-support` - Customer Support Agent
- `#financial-analyst` - Financial Data Analyst
- `#autonomous-coding` - Autonomous Coding

### Nach Typ
- `#setup` - Setup & Installation
- `#code-style` - Code Konventionen
- `#tool` - Werkzeug oder Dependency
- `#python` - Python-spezifisch
- `#typescript` - TypeScript-spezifisch
- `#docker` - Docker-bezogen
- `#cli` - Command Line Interface

### Nach Priorität
- `#important` - Wichtig
- `#frequently-used` - Oft verwendet
- `#reference` - Nachschlagewerk

## 📌 Tag-Beispiele

```
#computer-use #docker #setup
#python #code-style #important
#typescript #frequently-used
```

## 🔗 Suche mit Tags

Nutze in der Suche:
```
tag:#python
tag:#setup
tag:#important
```
